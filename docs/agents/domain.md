# 领域文档

## 开始探索前应阅读

- 根目录的 `CONTEXT.md`。
- `docs/adr/` 中与当前工作相关的 ADR。

若这些文件不存在，请直接继续，无需提示缺失。仅在术语或决策真正明确后，领域建模工作才会创建它们。

## 文件结构

单一上下文布局：

```
/
├── CONTEXT.md
└── docs/adr/
```

## 使用词汇表中的术语

在 Issue 标题、方案、假设和测试名称中使用 `CONTEXT.md` 已定义的术语。若确有缺失术语，记录给领域建模工作处理。

## 标明 ADR 冲突

若与现有 ADR 冲突，必须明确说明，不得静默覆盖。
