## 请求与排序

网页首屏分别返回两类作品的当前页与总数。相同作者 URL 接受 `Accept: application/json`，以 `type=original|translation`、`sort=hottest|newest`、正整数 `page` 请求单类作品。响应包含共用列表模板生成的 `html`、`next_url`（末页为 null）和 `total`。改变排序重置页码。

最热沿用评分门槛、加权均分、评分人数和总权重规则，无有效评分时按创建时间倒序。最新优先使用写作日期，缺月补年末、缺日补实际月末，缺年使用创建日期。最后以创建时间和 ID 决胜，保证同一数据集连续翻页顺序确定；offset 分页不提供跨并发修改的快照一致性。

原作包含作者名下作品及关联用户本人上传的原创；同时命中只出现一次。译作兼容旧译者字段和多态译者关系。两类均排除软删除与已合并作品。翻页只预加载当页译者及诗人标签。

页面仅展示已缓存的维基描述，不在渲染过程中同步抓取外部摘要，避免分页后仍受外部网络拖慢。现有小程序作者详情 API 不在本次变更范围。

## 验证

隔离真实 MySQL 测试库上的分页 HTTP 测试覆盖连续页、稳定决胜、归属去重、删除／合并过滤、加权评分、闰年月末、短年份与公元前年份、非法参数及末页。

上线前用新查询代码在生产库只读事务中测量目标作者：最热第一页 1.178 秒、第二页 1.145 秒，最新第一页 0.672 秒；每页 50 首，总数 25,190，CLI 峰值内存 12 MiB。这是查询测量，完整 HTTP 耗时另行验证。
